# 财务口径与判断约束

财务事实 → 个人基线 → 决策 → 长期反馈。后层不能改写前层事实，也不能按预算倒推基线。不足数据不制造趋势、目标失败、正常区间或模拟结果。

统计单位是经济事件。消费是本人最终承担额：`gross_expense - refund_amount - reimbursement_amount = net_expense`。退款、共同费用回款、报销和明确代付回款引用原事件，关联只应用一次。回款允许分配至多个事件，累计不超过到账金额。未收回款项单独保留 `unsettled_amount`。纯代付净额归零后仍保留原始支出和调整链。

内部资金移动不是消费或真实收入。工资、赠与等实际增加财富的款项按性质计收入。购买已计消费时，本金还款是现金流与偿债，利息/费用是独立消费；同一流水的分配合计须等于原始金额。不能把个人转账自动判为内部转账。

多条渠道流水可支持同一事件。次流水明确标为 duplicate 或 funding，并有已确认关联；只有一个主现金流。稳定事件 ID 用明确成员与拆分角色生成，不使用临时排序序号。相同金额、相近时间只能产生候选；订单、渠道、账户、用途与完整资金链共同支持正式归并。同额多候选保留歧义。导出行号只表示证据位置，不能当交易 ID；账户未知时不跨文件自动归并。

默认以支付发生日归期；跨期收到退款/回款分别保留本期现金流与原期经济净额修订。原期已存在摘要时，使用相同事件 ID 修订原期快照及指标，保留前后值。尚未建立原期摘要时，仅保留跨期事件事实；须独立分析原期，不能凭一个退款制造完整原期摘要。

分类随实际经济用途确定，不预设用户场景。一级与二级用途、支出属性、发生规律、基线纳入与可调整性互相独立。重复商户不证明订阅。长期预付、设备和阶段性事项与日常成本区分，不强制摊销。生活基线与个人消费基线分别标记；未知用 null，不以金额大小或必要性推断调整空间。

只有明确有效观测日和可靠覆盖才计算基线日均。固定长期付款不按短期样本机械放大。日均与30日等效是比较口径，不冒充整月现金支出。支出/收入部分覆盖时数值只代表已覆盖收支差额；资金留存率保持 null。完整收入为零时留存率为不适用。未知事件使相关经济总额降级为 null，原始现金事实仍可单列。

历史参考仅来自当前期之前、已审计、同币种、同精度、同场景组、同定义版本、同指标定义与单位、相关覆盖完整的合格期。原始整期金额还要求完整月份。至少两历史期才有中位数比较，最多最近六期；六期才有线性 P25—P75 描述区间。当前期不入参考集合，未来期、unknown/null 和不合格期不凑样本。零参照不计算变化比率。

目标建议是 proposed；accepted 与反馈状态须引用用户接受确认。按约定指标、期限和原口径验收；数据不足为 insufficient_data，不擅自判失败。修改目标保留准确前后快照与证据，不更改口径制造完成。

义务覆盖 unknown/partial 不等于没有义务。贷款本金、服务覆盖、到期额与已付状态须有证据。未来1/3/6个月承诺按截止日之后到自然月同日（月底夹取、含终点）汇总已确认未付计划；已付、取消、结束、结清排除。未知覆盖或计划保持 null。结束义务按 ID 保留，不删除记录。

金额用 Decimal 核对。一次只分析一种币种，不自动换汇、不混加；人民币默认两位，其余显式精度。核查阈值由当前币种与任务语境决定，不固化为消费价值判断。
